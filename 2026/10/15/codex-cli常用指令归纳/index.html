Codex CLI 常用指令速查手册

更新：2026-10-15 ｜适用：Windows PowerShell、Linux、WSL、VS Code 集成终端。

本文针对 Codex CLI 终端版。Codex 桌面应用与 VS Code 扩展的部分操作在图形界面完成。可用命令以本机 codex --help 和交互界面的 /help 为准。

1. 最常用的 10 条命令

场景 命令 说明
启动 codex 在当前目录开始会话
查看版本 codex --version 确认安装版本
查看帮助 codex --help 查看本机支持的参数
恢复最近对话 codex resume --last 恢复最近一次会话
选择历史对话 codex resume 从历史列表选择
跨目录查看历史 codex resume --all 查看其他目录的会话
恢复跨目录最近会话 codex resume --last --all 忽略当前目录限制
登录 codex login 登录 Codex
检查登录状态 codex login status 检查是否已登录
升级 npm 安装版 npm install -g @openai/codex@latest 更新到最新 npm 正式版

安装失败时先检查 node -v、npm -v，并确认 Codex 可执行文件在 PATH 中。若使用 Homebrew 安装，应采用对应的 Homebrew 更新方式，不要混用包管理器。

3. 恢复历史会话（重点）

使用建议：先进入原项目目录，再执行 codex resume --last，以免在错误目录操作代码。

常见本地会话目录：

  • Linux/WSL：~/.codex/sessions/
  • Windows PowerShell：$HOME\.codex\sessions\

若设置过 CODEX_HOME，实际位置可能改变。Windows、WSL 和远程 Linux 各有独立的用户目录，不一定共享历史。

4. 登录、退出与身份验证故障

如果遇到 refresh token was revoked 或访问令牌无法刷新：

  1. 先退出当前 Codex 会话。
  2. 执行 codex logout。
  3. 执行 codex login 重新认证。
  4. 执行 codex login status 检查是否成功。

不要将 API Key 或登录令牌放进公开仓库、截图或日志。

5. 交互会话中的斜杠命令

以下命令在 进入 codex 后 输入，不是 PowerShell / Bash 的普通命令。不同版本与运行环境可能有所差异，先输入 / 或 /help 查看可用项。

命令 用途
/help 查看交互命令帮助（若当前版本支持）
/status 查看会话、模型、工作区等状态
/model 切换模型 / 推理设置（依可用版本而定）
/review 请求代码审查
/compact 压缩过长的对话上下文
/plan 切换规划模式（支持时）
/goal <目标> 创建持续目标（支持时）
/goal pause 暂停持续目标
/goal resume 继续持续目标
/goal clear 清除持续目标
/fork 从当前上下文分叉新会话（支持时）
/fast 切换速度模式（支持时）
/feedback 提交反馈

/goal resume 用于暂停的 Goal，不同于终端中的 codex resume（恢复历史聊天）。

常见用户配置路径：

  • Linux/WSL：~/.codex/config.toml
  • Windows：$HOME\.codex\config.toml

8. MCP 扩展管理

MCP 可将 Codex 连接到额外工具。请只添加可信服务器，检查其文件与网络权限。

9. 快速排障

A. 提示 codex 不是命令

确认 npm 全局安装目录已加入 PATH，然后重开终端。

C. 找不到历史对话
