从多张 Excel 到一个系统：玉磊团队做了一套「先锋助理员管理系统」

排班靠 QQ 群、工时靠 Excel、发工资靠人工核对、办活动靠手画座位图——
这套系统，把这些事全接了过去。

一、写在前面：那些被琐事吃掉的时间

每个学生组织的助理员团队，大概都经历过这样的场景：

  • 排班：负责人打开一张排班表，一个个对照成员的无课时间，排完还要在群里反复确认「你周三下午有课吗」
  • 工时：月底翻出七八张 Excel，手工加总，一不小心漏了谁，就要重头再来
  • 工资：工时统计完，还要按部门核对额度、生成工资条、挨个发下去、收回执
  • 办活动：几百号人的表彰大会，座位图要在 Excel 里一格一格填名字，领导座次还有讲究，填错一个要全部重来
  • 交接：老师布置的大任务，几个值班时段根本做不完，换班的人不知道上一班做到哪了

这些事情单看都不难，但加起来就是每个月几十个小时的重复劳动，而且极易出错——尤其是工资和座次，错一次就要重新来过。

于是我们做了一个决定：把它做成一个系统。

二、系统是什么

先锋助理员管理系统是一套面向高校学生助理员团队的内部管理平台，覆盖成员、排班、工时、工资、活动、物资、交接全流程。

  • 🌐 网页端：https://zzbsystem.top（已备案域名 + HTTPS）
  • 📱 移动端：微信小程序，绑一次微信即可免密登录
  • 🔐 四类角色：总负责人 / 部门负责人 / 成员 / 教师，各看各的、各管各的

三、八大模块

1️⃣ 数据看板 · 指挥中心

打开就是一块实时大屏：环形图看部门分布、柱状图看本周值班趋势、待办事项按类别带数字和直达按钮。

打开「指挥中心」，今天谁值班、签到情况如何、哪些申请待处理，一屏就能看清。深色大屏将核心数据、值班趋势和分类待办集中呈现，当前班次的人员、联系方式与签到状态也一目了然。从掌握全局到联系值班同学、进入审批页面，负责人可以顺着信息直接行动。

2️⃣ 值班排班：自动排 + 定位签到

这是每天都要用的模块。

  • 自动排班：系统读取全员的无课时间，自动生成排班表，冲突的自动避开
  • 定位签到：值班当天在小程序点签到，系统用 GPS 围栏判断是否在值班地点范围内，不在范围内会提示——代签基本不可能
  • 请假审批：成员提交请假，负责人一键通过或驳回
  • 今日值班：教师也有独立视图，能看到今天值班人员的姓名、电话、值班时间段
  • 学籍标识：名字后面自动挂「本」或「研」（银色 / 绿色小标签，仅总负责人可见）


3️⃣ 工时管理：从录入到审核，一条链

  • 部门负责人录入工时，总负责人审核，通过后才计入工资
  • 成员可以自己发起工时补录申请（比如漏记了一次值班），写明日期、事由
  • 部门负责人能看到自己部门的申请，总负责人能看到全部
  • 两级审批：部门负责人或总负责人任一通过即可生效——不影响效率，也留了痕

4️⃣ 工资条：生成、发送、确认全在线上

  • 总负责人按月份一键批量生成工资条，按部门额度自动汇总
  • 未结清的工时自动顺延到下个月，明细里会写清楚「6 月剩余未结工时」
  • 工资条推送到成员端，成员在小程序里查看、确认或提出疑问
  • 全流程留痕，谁什么时候确认的，一查便知

6️⃣ 任务交接：老师布置的大任务，不再”断档”

这是后来加的一个模块，解决一个很具体的痛点：

老师安排了一个大任务，横跨好几个值班时段。A 班做完一半走了，B 班来了不知道做到哪了。

现在：任何人都可以创建任务，每个值班的人在自己的班次下汇报进度，可以写文字，也可以直接传图片、Excel、Word、PPT、PDF（单个最大 20MB）。后面接手的人打开任务，从头到尾的进度一目了然。

7️⃣ 智能管家：用大白话查数据

总负责人专属的一个 AI 助手，接的 DeepSeek 大模型。

它的定位很克制：只查不改。你可以直接问：

「今天谁值班？」
「还有多少工时没审？」
「下个月有哪些活动？」

它会直接查数据库给你答案，还会附上可点击的直达链接，点一下就跳到对应页面。

因为不能修改任何数据，所以也不怕问错——它是助手，不是操作员。

8️⃣ 其他协作模块

模块 能干什么
成员管理 按部门 / 班级 / 政治面貌筛选，实时显示筛选后人数
人员库 · 排序库 校级领导职务、部门排序预设，办活动时自动套用顺序
物资统计 物资台账 + Excel 批量导入
规章制度 在线查阅，支持导入 Word
留言板 团队内部交流，重要留言可置顶
操作日志 所有增删改自动留痕，60 天自动清理

四、移动端：微信小程序

所有高频操作都做了小程序：查看值班、定位签到、请假、查工资条、确认工资条、看物资。

绑一次微信，以后免密登录——值班当天掏出手机点一下就能签到，不用再输账号密码。


五、技术上做了什么

给技术读者的一句话版本：

层面 选型
后端 Python 3.12 + FastAPI + SQLAlchemy + MySQL
前端 Vue 3 + TypeScript + Element Plus + Vite
移动端 微信小程序
部署 Nginx 反向代理 + HTTPS + 阿里云轻量服务器
AI DeepSeek API（Function Calling）
实时 WebSocket 长连接推送

有几个点值得单独说：

  • 实时同步：值班表一改，所有正在打开页面的用户自动刷新，不用手动 F5。用的是 WebSocket 长连接 + 心跳保活
  • 待办红点：侧边栏按角色显示待办数量，有新申请自动 +1
  • 失败原因透明：Excel 导入失败会明确告诉你哪一行、哪一列有问题，不用瞎猜
  • 安全：JWT 鉴权、密码 BCrypt 加密（不可逆）、GPS 签到围栏、全量操作日志

七、结语

这套系统的出发点其实很朴素：把重复的事交给程序，把时间还给人。

它不复杂，也没什么黑科技。但从排班到工资，从座次到交接，每一处都对应着一个真实存在的、让人头疼过的具体问题。

如果你们团队也在被类似的事情消耗，欢迎交流。
